# vz

React and TypeScript starter using Vite+ 1.6.0 and Void 1.8.0.

## Development

Install the [Vite+ CLI](https://viteplus.dev/guide/global-cli), then run:

```sh
vp install
vp dev
```

Open http://localhost:5173. Edit `pages/index.tsx` to change the home page.

```sh
vp check   # Check formatting, linting, and types
vp build   # Build for production
vp preview # Preview the production build
```

The starter uses Void Pages without a database. See the
[Void documentation](https://void.cloud/guide/quickstart) to add server routes,
databases, or deployment.
